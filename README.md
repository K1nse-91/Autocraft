# AutoCraft 自动合成

Minecraft 1.21.11 Fabric 客户端模组：打开工作台后自动合成指定物品与数量；材料不足时自动前往「展示框标记的补给箱」取料；支持成品自动装箱（黄玻璃标记的存放盒）。**baritone 寻路已内置，无需单独安装。**

## 功能

- **自动合成**：选定目标物品与数量（±64/±1728 快捷调节），打开工作台即开始，成品计数按背包实物结算，准确不漂移
- **三态成品去向**：丢出合成 / 存放背包 / 装箱合成（点击面板按钮循环切换）
  - 装箱合成：成品自动存入「展示框放黄色染色玻璃」标记的潜影盒，每 320 个自动装盒一次，大批量不占背包
- **自动补货**：材料不足自动前往补给点
  - 补给点 = 展示框标记容器：框里放什么物品，该容器就专供什么（箱子 / 任意颜色潜影盒均可）
  - 摆放：潜影盒可放在展示框所贴方块的下方或水平两侧；容器也可直接贴着展示框
  - 按需求比例分配取料，多种材料不会只拿一种
  - 补给箱被拿空时自动等待补货机补货（快速重试），补上即继续
- **物品搜索支持拼音**：`bh` → 白桦、`baihua` → 白桦原木（支持中文名/注册名/全拼/首字母缩写）
- 完成后自动关闭模块开关；快捷键可在游戏内「选项-控制-按键绑定」修改并持久化
- baritone（jar-in-jar）与拼音库均已内置，只依赖 Fabric API

## 使用

1. 需要 Fabric Loader + Fabric API 的 1.21.11 客户端
2. 把 `autocraft-1.0.0-1.21.11.jar` 放入 `mods/` 目录
3. 游戏内按 `J` 打开控制面板：选择物品、数量与成品模式
4. 按 `K`（或面板开关）开启模块，然后打开工作台

> 快捷键可在 选项 → 控制 → 按键绑定（杂项）中修改。

## 默认按键

| 功能 | 按键 |
|---|---|
| 模块开关 | K |
| 控制面板 | J |

## 构建

```bash
./gradlew build
# 产物: build/libs/autocraft-1.0.0-1.21.11.jar
```

需要 JDK 21。`libs/` 下的 jar 已随仓库提供（baritone 运行时内置、pinyin4j 拼音库）。
